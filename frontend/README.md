# Frontend

TanStack Start uses file-based routing. Every `.tsx` file in `src/routes`
defines a route. The only root layout is `src/routes/__root.tsx`.

| File | URL |
| --- | --- |
| `src/routes/index.tsx` | `/` |
| `src/routes/about.tsx` | `/about` |
| `src/routes/users/$id.tsx` | `/users/:id` |

`src/routeTree.gen.ts` is generated by TanStack Router and must not be edited
by hand. Run the frontend commands from this directory:

```bash
npm install
npm run dev
npm run build
```
