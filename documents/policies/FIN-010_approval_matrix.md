# FIN-010: Approval Matrix

**Policy ID:** FIN-010
**Version:** 2.0
**Effective Date:** 2025-06-01
**Owner:** Finance Department — CFO

## Scope
Defines the approval authority levels for all financial actions at Northstar Technologies.

## Approval Matrix

| Action | Finance Analyst | Finance Manager | Controller | CFO |
|--------|:-:|:-:|:-:|:-:|
| View transactions | ✓ | ✓ | ✓ | ✓ |
| Run investigation | ✓ | ✓ | ✓ | ✓ |
| Approve discount ≤ $250 | ✓ | ✓ | ✓ | ✓ |
| Approve discount $251–$2,500 | ✗ | ✓ | ✓ | ✓ |
| Approve discount > $2,500 | ✗ | ✗ | ✓ | ✓ |
| Create journal entry ≤ $2,500 | ✓ | ✓ | ✓ | ✓ |
| Create journal entry > $2,500 | ✗ | ✓ | ✓ | ✓ |
| Process refund | ✗ | ✓ | ✓ | ✓ |
| Write-off ≤ $500 | ✗ | ✓ | ✓ | ✓ |
| Write-off > $500 | ✗ | ✗ | ✓ | ✓ |
| Close period | ✗ | ✗ | ✓ | ✓ |
| Reopen period | ✗ | ✗ | ✓ | ✓ |
| Manage users | ✗ | ✗ | ✗ | ✓ |

## Rules
1. Approval authority cannot be delegated below the minimum required level.
2. Self-approval is not permitted for amounts exceeding $1,000.
3. Emergency approvals must be documented and reviewed within 48 hours.
